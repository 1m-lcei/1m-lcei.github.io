# Article service marks

The source SVGs were downloaded on 2026-10-04 and retained unchanged as zenn.svg.txt and gist.svg.txt. The served public/article-icons.svg places their original vector paths in symbols with additional clear space. WorkCard uses SVG/use to identify the destination services.

| Mark | Source | Use guidance |
| --- | --- | --- |
| Zenn blue logo mark | [Official media kit](https://zenn.dev/mediakit), [official ZIP](https://static.zenn.studio/images/mediakit/zenn-logo.zip), zenn-logo/logo-only.svg | The mark may stand alone. Keep full color, shape and aspect ratio; add no decoration. Clear space is about half the mark size on every side. |
| Gist card: angle-bracket code icon | [GitHub Octicons code-24.svg](https://github.com/primer/octicons/blob/main/icons/code-24.svg), [MIT license](https://github.com/primer/octicons/blob/main/LICENSE) | Keep the source paths and render black with added clear space. The full upstream copyright and MIT notice are in OCTICONS_LICENSE.txt and a comment in the served sprite. |

The user selected the angle-bracket code symbol for the Gist card. It is the general GitHub code icon from Octicons, not a claim that this is a Gist-specific official logo. The source paths are unchanged and the MIT copyright and permission notice are retained. The Zenn logo continues to follow its official media-kit guidance.
